# Бизнес-правила и расчёты в Oracle

Приложение переводится с PostgreSQL на Oracle по заданию курсового с доступом к данным через процедуры. Oracle становится единственным владельцем бизнес-проверок, финансовых расчётов и атомарных изменений; Avalonia-приложение отвечает за представление и интеграции. Это исключает расхождение правил между ручным вводом и импортом, но связывает реализацию бизнес-логики с PL/SQL.
