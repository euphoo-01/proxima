# Независимые контракты источников и хранения

Потребители котировок и хранилищ зависят от универсальных контрактов, определённых потребностями приложения. Для каждого источника котировок создаётся конкретный адаптер, для хранения — реализация репозитория с вызовами процедур Oracle. Существующие подходящие интерфейсы переиспользуются: это позволяет заменять поставщиков без распространения их форматов и правил доступа по приложению, сохраняя бизнес-расчёты в БД.
