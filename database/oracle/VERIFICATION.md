# Проверка первого Oracle-среза

18 ноября 2026 года, локальный Docker. Реально запущена Oracle AI Database 26ai Free 23.26.3.0.0, PDB `FREEPDB1`.

- Сопоставление с исходной ER: 21 таблица, 148 полей, 32 связи из диаграммы и дополнительный составной FK согласованности портфеля операции и позиции. Поля и таблицы ER не менялись.
- Проверка каталога БД: 21 таблица, 148 полей, 33 внешних ключа; невалидных объектов владельца — 0.
- `bash database/oracle/scripts/oracle.sh smoke`: успешно вызваны три процедуры `PKG_REFERENCE` под `PROXIMA_APP`, возвращены 3 валюты и 4 инструмента.
- `DBMS_DATA_MINING` существует и имеет статус VALID. Это не проверка обучения моделей: сами модели ещё не создавались.
- На настоящем сервере обнаружены и исправлены ограничение UNIQUE для TIMESTAMP WITH TIME ZONE и дублирующий индекс. Частично установленная схема доведена до согласованного состояния без удаления объектов. В исходном DDL исправлены причины ошибок; чистое повторное развёртывание на другом volume отдельно не выполнялось.
- Unicode для EUR проверен через `ASCIISTR`: `\20AC`; SQL*Plus запускается с AL32UTF8, seed использует `UNISTR`.

Авторизация приложения, операции, FIFO, налоги, импорт и ML пока не перенесены. Прикладному пользователю выдан только EXECUTE на API открытых справочников, прямое чтение таблиц не разрешено. Ни одна из будущих финансовых функций не считается готовой на основании одного DDL.
